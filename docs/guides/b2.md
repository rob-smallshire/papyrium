# Printing from b2

b2 keeps everything its BBC Micro prints in a buffer, which you save to a
file when you want it. Papyrium prints the saved file as a job.

## Set up b2

**Printer > Parallel printer** attaches the printer. b2 does not remember
it: attach it again each time you start b2. The Printer menu shows how
many bytes have been printed.

## Print

On the BBC, as described in [the guides' introduction](README.md#on-the-bbc).

Then, in b2:

1. **Printer > Save printer buffer...** and save the bytes, such as
   `b2-printer.dat`.
2. **Printer > Reset printer buffer**, so that the next save holds only
   the next job.

## Print the saved file

```sh
papyrium print b2-printer.dat
```

prints it as a job in `papyrium-jobs`, as `papyrium serve` would have,
numbered after the jobs already there; choose the printer with `--model`.
Or, with `papyrium serve` running, send it to that printer, so that it
joins its other jobs:

```sh
papyrium send b2-printer.dat
```

Use **Save printer buffer**, not **Copy printer buffer**: the copy is
text, with the printer's control codes removed.

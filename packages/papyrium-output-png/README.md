# papyrium-output-png

A Papyrium output that writes each page as a greyscale PNG
(`page-0001.png`, `page-0002.png`, ...), drawing every dot the print head
struck as a round dot of ink on white paper. Registered as `png` on the
`papyrium.output` axis.

Options: `dpi` (default 360), `ink` and `paper` grey levels (0 black to
255 white).

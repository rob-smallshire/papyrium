# papyrium.font.mps803

mps803 is the Commodore MPS-803's character set, extracted by
`tools/mps803-rom/extract.py` from the character generator in the
printer's uPD78C11 ROM. The characters are Commodore's. 159 glyphs, 7
rows by 6 columns: full dots 1/60 inch apart, one to a carriage step,
letters in five columns and graphics in six, so that they join. It
covers both of the printer's sets, PETSCII's upper case and graphics and
its lower and upper case, each glyph keyed by the Unicode character it
shows, PETSCII's graphics among the Symbols for Legacy Computing; the
zero is slashed, and lower case has no descenders.

Registered as `mps803` on the `papyrium.font` axis.
